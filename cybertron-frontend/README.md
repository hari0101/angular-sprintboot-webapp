# Cybertron Frontend

Angular frontend for the Cybertron application.

## Prerequisites

- Node.js
- NPM
- Angular CLI

## Configuration

The frontend is configured to communicate with the backend on `http://localhost:8081`.
The frontend itself runs on `http://localhost:4200` by default.

## Running the Application

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    ng serve
    ```

    Open your browser and navigate to `http://localhost:4200/`.

## Features

- **Chat Interface**: Communicates with the backend.
- **Health Check**: Monitors the status of the backend service.
